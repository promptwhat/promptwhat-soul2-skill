# 기본 명령어 모음

soul2-prompt 스킬과 함께 쓰는 **기본 명령어 모음**입니다. 참고용이니 외울 필요 없습니다. 필요할 때 여기서 골라 쓰세요.

전부 평소 말하듯이 쓰면 됩니다. 정해진 형식이 없어서, 아래 문장을 그대로 옮기지 않고 비슷하게 말해도 알아듣습니다.

<br>

## 1. 시작하기

| 이렇게 입력하세요 | 나오는 것 |
|---|---|
| `소울로 하나.` | 컨셉까지 스킬이 정해서 1장 |
| `소울로 하나. 비 오는 날 편의점 앞 감성으로` | 그 컨셉으로 1장 |
| `소울로 하나. 여름 밤 놀이공원, 청량하게` | 그 컨셉으로 1장 |

컨셉은 러프해도 됩니다. 장소, 인물, 의상, 조명, 색은 **스킬이 알아서 정합니다.** 직접 정하신 것(`빨간 원피스로`)은 **절대 바뀌지 않습니다.**

<br>

## 2. 여러 장 뽑기

| 이렇게 입력하세요 | 나오는 것 |
|---|---|
| `세트로` | **같은 인물이 같은 옷으로** 6장 |
| `6장으로` / `10장으로` | 그 숫자만큼 |
| `인물 바꿔가며` | 장마다 다른 사람이 나오는 룩북형 |

`세트로`가 기본이고, 인물과 의상과 색이 장마다 이어집니다. 바뀌는 것은 장면, 행동, 구도뿐입니다.

얼굴까지 더 조이는 방법은 두 가지입니다. 스킬이 세트를 낼 때마다 끝에 안내해 줍니다.

| 방법 | 어떤가 |
|---|---|
| **첫 장을 참고 이미지로 걸기** | 추가 비용 없이 닮은 정도가 올라갑니다. 다만 장수가 많아지면 조금씩 흔들립니다 |
| **Soul ID (Character 탭)** | 사진 20장 이상으로 인물을 미리 학습시켜 두는 힉스필드 기능입니다. 여러 장·여러 날에 걸쳐도 유지됩니다. 요금제에 따라 쓸 수 있습니다 |

<br>

## 3. 인물 정하기

| 이렇게 입력하세요 | 결과 |
|---|---|
| `남자로` | 남성 인물로 |
| `20대 초반으로` / `30대로` | 나이대 지정 |
| `동양인으로` / `서양인으로` | 인종 지정 |
| `두 명으로` / `쌍둥이로` | 여러 명 |
| `키 크고 마른 체형으로` | 체형 지정 |

말하지 않으면 스킬이 컨셉에 맞게 정합니다. 비슷한 사람만 계속 나올 때는 `아까랑 다른 느낌 사람으로` 라고 하면 됩니다.

<br>

## 4. 구도 정하기

| 이렇게 입력하세요 | 결과 |
|---|---|
| `클로즈업으로` | 얼굴 위주 |
| `전신으로` | 발끝까지 |
| `상반신으로` | 허리 위 |
| `멀리서 넓게` | 배경이 많이 보이게 |
| `위에서 내려다보는 각도로` | 하이앵글 |
| `아래에서 올려다보는 각도로` | 로우앵글 |

<br>

## 5. 프리셋 바꾸기

프리셋은 힉스필드가 미리 만들어 둔 스타일입니다. **고르실 필요가 없습니다.** 스킬이 컨셉에 맞는 것을 골라서, 결과 맨 위 설정값 줄에 무엇을 골랐는지 적어 줍니다.

```
[프리셋: Candy pop | 비율 3:4 세로 | enhance 끔]
```

아래는 다른 것으로 바꾸고 싶을 때만 보는 표입니다. `Drain으로 바꿔줘` 처럼 말하면 됩니다.

| 프리셋 | 어떤 느낌 |
|---|---|
| **General** | 기본. 프롬프트가 스타일을 전부 결정 |
| **Theatrical light** | 무대 조명 같은 극적인 빛, 고딕이나 발레 |
| **Candy pop** | 파스텔 인형 같은 소녀 판타지 |
| **Old smartphone** | 옛날 휴대폰 카메라 질감 |
| **Flash editorial** | 정면 플래시를 터뜨린 밤 화보 |
| **Drain** | 채도를 뺀 시크한 도시 느낌 |
| **New Indie** | 인디 스냅 |
| **Surreal solarization** | 명암이 뒤집히는 실험적인 톤 |

<br>

## 6. 분위기와 색 정하기

| 이렇게 입력하세요 | 결과 |
|---|---|
| `더 밝게` / `더 어둡게` | 전체 밝기 |
| `파스텔 톤으로` / `채도 높게` | 색감 |
| `초록색 위주로` | 특정 색을 중심으로 |
| `필름 느낌으로` | 아날로그 질감, 살짝 거친 입자 |
| `폰카로 찍은 느낌으로` | 직접 찍은 듯한 자연스러움 |
| `잡지 화보처럼` | 매끈한 고화질 화보 |
| `밤으로` / `해질녘으로` / `아침으로` | 시간대 |
| `겨울로` / `여름으로` | 계절 |

<br>

## 7. 초현실로 만들기

| 이렇게 입력하세요 | 결과 |
|---|---|
| `이상하게` / `초현실로` | 현실에 없는 장면 |
| `소품을 크게` | 물건이 사람보다 커지는 장면 |
| `꿈같이` | 몽환적으로 |

이 말을 하지 않으면 현실적인 사진으로 나옵니다. 초현실은 직접 부를 때만 나옵니다.

<br>

## 8. 결과 고치기

이미 나온 결과를 손볼 때 쓰는 말입니다.

| 이렇게 입력하세요 | 결과 |
|---|---|
| `옷만 바꿔` | 인물과 장소는 두고 코디만 |
| `배경만 바꿔` | 인물과 의상은 두고 장소만 |
| `소품 빼줘` | 손에 든 물건 제거 |
| `더 화려하게` / `더 심플하게` | 밀도 조절 |
| `이건 빼고 다시` | 마음에 안 드는 요소 제거 |
| `다시` / `다른 걸로` | 통째로 새로 |

고쳐달라고 하면 바뀐 부분만 주지 않고 프롬프트 전문을 다시 냅니다. 그대로 복사하시면 됩니다.

<br>

## 9. 결과 받아 쓰기

나오는 것은 항상 세 덩어리입니다.

1. **설정값 줄**, 프리셋과 비율 같은 정보
2. **영어 프롬프트**, 이것만 복사해서 힉스필드에 붙여넣으세요
3. **한국어 번역**, 무엇을 만드는지 확인하는 용도

비율은 세로 3:4가 기본입니다. 힉스필드의 enhance(자동 확장)는 꺼두시면 됩니다. 스킬이 이미 완성된 프롬프트를 주기 때문에, 켜면 두 번 가공돼서 의도가 흐려집니다.
